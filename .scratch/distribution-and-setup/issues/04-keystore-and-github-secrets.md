# 04: Keystore and GitHub secrets

A `/wizard` script walks the maintainer through generating the keystore, setting the secrets and checking the backup. The README states that losing the key means players must uninstall before updating.

**Blocked by:** 03 (Signed release build in CI), which defines the secret names.
